# Working agreement

Keep code, commands, UI, logs, and documentation in English.
Keep browser ownership in the worker, independent of Next.js request lifetimes.
Keep discovery providers out of the replay dependency graph.
Use typed browser actions and declarative conditions; do not execute model-generated browser or shell code.
Codex may dispatch those tools through its sandboxed JavaScript orchestration runtime, without native environments or unrestricted host tools.
Route every automated browser action through policy and session ownership checks.
Use synthetic data only and never commit credentials, raw browser profiles, or local run state.
Use comments only for constraints that the code cannot explain itself.
Keep actual run evidence separate from fixtures and planned behavior.
Do not describe this project as production banking software or as proof of model superiority.
Update architecture diagrams when implementation boundaries change.
Run the authorized verification gates before claiming completion.
Do not commit, push, publish, or deploy without explicit authorization.
